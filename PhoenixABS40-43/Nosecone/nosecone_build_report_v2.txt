Phoenix ABS 40-43 -- Nosecone v2 (fairing split) -- build report
Generated by PhoenixABS40-43_Nosecone_v2.py, run via FreeCADCmd headless.
See NOSECONE_DESIGN.md for rationale. Supersedes nosecone_build_report_v1.txt
(v1 kept for history -- small door-window design, since replaced).

WHY V2: user feedback on v1 -- (1) ogive faceted visibly, (2) "the door
should BE the nosecone... at least 1/2 of it should detach... think like a
fairing." V2 rebuilds the ogive as a true circular arc (exact, not a
polyline) and splits the whole nosecone lengthwise into a fixed Spine +
hinged/latched DoorHalf.
